# 🚗 Car Rental by Vasi

Car Rental by Vasi is a comprehensive **JavaFX desktop application** designed to simulate and manage the workflow of a car rental business.  
It integrates a **MySQL database** for persistent storage, supports **CRUD operations**, and provides a modern, user-friendly interface for both customers and administrators.  

This project demonstrates practical skills in **object-oriented programming, database connectivity, and GUI development**, making it an excellent showcase for academic evaluation, portfolio presentation, or professional documentation.

## 📋 Overview
The application provides a **complete car rental management system**.  
Customers can browse available cars, make reservations, and return vehicles, while administrators can manage customer records, vehicle inventory, and rental transactions.  

The project emphasizes:
- **Database-driven design** with MySQL.
- **Interactive GUI** built using JavaFX.
- **Scalable architecture** suitable for real-world adaptation.

---

## ✨ Features
- 🧾 **Customer Management**
  - Add, update, and delete customer records.
  - View customer details with search functionality.

- 🚘 **Vehicle Inventory**
  - Maintain a list of cars with attributes such as model, type, availability, and rental price.
  - Update car status dynamically when rented or returned.

- 📅 **Reservation System**
  - Book cars for specific dates.
  - Track rental periods and calculate charges.
  - Manage returns with automatic status updates.

- 🔐 **Admin Dashboard**
  - Secure login system for administrators.
  - Centralized control panel for managing customers, vehicles, and reservations.

- 💾 **Database Integration**
  - Persistent storage using MySQL.
  - Real-time updates with JDBC connectivity.

- 🎨 **Modern UI**
  - Clean, responsive design using JavaFX.
  - Intuitive navigation with FXML-based layouts.
